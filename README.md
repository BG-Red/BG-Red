### ⚡ About Me

I am a **Full-Stack Systems Architect & Product Engineer** specializing in turning ambitious technical concepts into production-grade software. My engineering spans autonomous AI agent systems, high-performance cross-platform mobile apps, and scalable web SaaS platforms.

Whether it's building a 60 FPS vector play-designer, orchestrating autonomous incident-triage runbooks, or architecting global cloud infrastructure, I focus on clean systems design, rock-solid DX, and zero bloat.

- 🔭 **Currently Engineering:** Enterprise agent runbooks & multi-tenant sports technology SaaS.
- 🎯 **Core Competencies:** Full-Stack Architecture, Autonomous AI Agents (MCP), Cross-Platform Native Apps, Cloud Systems.
- 💬 **Ask me about:** React Native & Skia, Flutter, Model Context Protocol, Firebase/Azure architecture, System Automation.
- ⚡ **Philosophy:** *"Ship fast, architect for resilience, and never compromise on user experience."*
